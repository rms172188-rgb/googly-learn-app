MOBILE-FIRST DESIGN — VERY IMPORTANT

The majority of students will use Android phones.

Therefore, design the entire website mobile-first, not desktop-first.

The website must look and work perfectly on:

- Small Android phones

- Large Android phones

- Tablets

- Desktop

- Laptop

Test the UI mentally for screen widths around:

- 320px

- 360px

- 375px

- 390px

- 412px

- 768px

- 1024px

- Desktop

Never allow horizontal scrolling on normal pages.

All content must fit naturally within the mobile screen.

==================================================
